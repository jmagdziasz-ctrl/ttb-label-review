TTB Label Compliance Review Prototype

Checks a label image against the submitted application — automatically catches simple mismatches so agents can focus on judgment calls.

Labels can be read two ways: a free, built-in offline reader (no account or setup needed), or Claude's AI image reading, which is more accurate on blurry, angled, or low-quality photos. Which one is active right now is shown below — use the button to switch between them and compare.

Currently using: the free built-in reader.

Forces every review to use the free reader instead of AI reading — handy for comparing the two, or as a fallback if AI reading ever has an issue.

Advanced: use your own Anthropic API key instead

If you have your own Anthropic API key, you can enter it to use AI reading under your own account rather than this app's default — this costs a small amount per label reviewed on your account.

This key is not saved permanently — it's kept only for as long as this browser tab stays open, and is cleared automatically when you close it (so it won't sit around on a shared or public computer). You'll need to re-enter it each new browser session. It's sent with each review request straight to this app's own server, which uses it to call Claude on your behalf; it's never sent anywhere else, and you can remove it early at any time.

Don't have a key? Here's how to get one
  1. Go to console.anthropic.com and sign up or log in.
  2. Go to Settings → API Keys, click Create Key, and copy it (it's only shown once).
  3. Add a payment method under Settings → Billing — usage is billed per request, typically a few cents per label reviewed.
  4. Paste the key above and click "Use for This Session".
