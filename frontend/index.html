Batch Review

For importers dropping off many applications at once. Upload a manifest spreadsheet plus all the label images — each image is matched to its application row by filename.

  1. Download the manifest CSV template, fill in one row per label.
  2. Select all the label images (the filename column must match each image's file name).
  3. Click Review Batch.
