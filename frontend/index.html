Quick Batch — no spreadsheet needed

Paste in the application details you already have — for however many labels — and this builds the batch for you. No manifest file to create by hand.

  1. Paste all your applications into the box below, with a blank line between each one — see an example. (Or, if you have them as separate files, use the file picker instead.)
  2. Select all the label photos. Name each photo to match its application — the first application becomes photo 1 (e.g. 1.jpg), the second 2, and so on. A file-based application keeps its own file name instead (e.g. smith_brand.txt pairs with smith_brand.jpg).
  3. Click Review Batch.
Brand Name: OLD TOM DISTILLERY
Class/Type: Kentucky Straight Bourbon Whiskey
Alcohol Content: 45% Alc./Vol. (90 Proof)
Net Contents: 750 mL
Bottled By: Old Tom Distillery, Bardstown, KY

Brand Name: RIVERBEND DISTILLERS
Class/Type: Blended Whiskey
Alcohol Content: 40% Alc./Vol. (80 Proof)
Net Contents: 750 mL

That's two applications (separated by the blank line) — they'd become photos 1.jpg and 2.jpg. Any of these lines can be left out if the application doesn't have it; only Brand Name, Class/Type, and Net Contents are needed for a label to be checked at all.

Manifest Spreadsheet — if you already have one

Already have a spreadsheet of applications? Upload it directly instead of pasting text above.

  1. Download the manifest CSV template, fill in one row per label.
  2. Select all the label images (the filename column must match each image's file name).
  3. Click Review Batch.
